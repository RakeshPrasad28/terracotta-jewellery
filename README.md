# MRITTIKA | Handcrafted Terracotta Jewellery & Artisan Accents

> **"Molded by Earth, Fired in Sacred Fire, Styled for Modern Royalty."**

An e-commerce and interactive bespoke customizer web application for handcrafted terracotta jewellery (Necklaces, Earrings/Jhumkas, Artisan Sherwani/Kurta Buttons, and Festive Sets). Designed for transition from offline craft exhibitions into a luxury online brand.

---

## ✨ Features & Architecture

### 1. 🏺 Handcrafted Product Catalog
- **Necklaces**: Haslis, Temple Chokers, Layered Mala Strings with riverbed clay medallions.
- **Earrings**: Feather-light bell jhumkas, chandbalis, and everyday geometric terracotta studs.
- **Artisan Buttons**: Kiln-baked buttons for royal Sherwanis, Kurtas, Nehru Jackets, and Saree blouse fasteners.
- **Festive Sets**: Complete coordinated suites for weddings and festive seasons.
- **Filtering & Search**: Category tabs, real-time search, and 🪔 *Navratri & Festive Only* filter toggle.
- **Quick View Modal**: High-resolution image zoom, artisan specifications (firing temperature, weight, clay type), and terracotta care guide.

### 2. 🪔 Bespoke Customizer Studio ("Design Your Own Piece")
- **Base Item Selection**: Necklace, Jhumkas/Chandbalis, Button Set of 6, Full Ensemble.
- **Sacred Festive Themes**: Navratri & Garba Raas, Sacred Temple & Divinity, Flora & Peacock, Folk Dokra Fusion.
- **Clay Glazes & Pigment Palettes**: Raw Baked Terracotta, Burnt Ochre & 24k Gold, Sacred Crimson, Midnight Indigo, Forest Sage.
- **Artisan Finishes**: Pure Matte Riverbed, Hand-painted 24k Gold Foil Strokes, Chiming Ghungroo Bells.
- **Live SVG Preview**: Real-time visual mockup updates instantly with selected motif, color, and finish.
- **Dynamic Pricing & Crafting Timeline**: Real-time price calculation with confetti celebration on adding bespoke order to bag.

### 3. 🛍️ E-Commerce & Checkout Simulation
- **Slide-over Shopping Bag Drawer**: Free shipping progress bar (Free shipping across India on orders ₹999+).
- **Promo Coupons**: Try `EARTH10` (10% Earth discount) or `NAVRATRI` (₹200 festive discount).
- **Saved Favourites / Wishlist**: Slide-over drawer to store and quickly move pieces to bag.
- **Express Checkout Modal**: Customer shipping address form, payment options (UPI/QR, Card, Cash on Delivery), and order confirmation with order ID.

### 4. 🌿 Heritage Brand Story & Reviews
- **From Riverbed Clay to Heirloom**: 4-step kiln craft pillars (Sacred River Silt, Freehand Sculpting, 850°C Kiln Baking, Organic Glaze).
- **Why Terracotta?**: 60% lighter than brass/silver, 100% skin-safe & hypoallergenic, zero plastic.
- **Offline Patrons Love**: Real testimonials from craft bazaars and exhibitions in Kolkata, Ahmedabad, and Bengaluru.

## 🚀 Tech Stack

- **React 19**
- **Tailwind CSS v3** (Custom terracotta, baked clay, ochre, and warm gold color design tokens)
- **GSAP** (Smooth entrance animations and staggered reveals)
- **Lenis** (Buttery smooth momentum scrolling)
- **Lucide React** (Icons)
- **Canvas-Confetti** (Festive celebration animations)
- **Vite**

## 💻 Running Locally

1. Open your terminal and navigate to the project directory:
   ```bash
   cd /Users/rakeshprasad/Desktop/terracotta-jewellery
   ```

2. Start the Vite development server:
   ```bash
   npm run dev
   ```

3. Open your browser and visit:
   ```
   http://127.0.0.1:5173/
   ```

4. To build for production:
   ```bash
   npm run build
   ```
